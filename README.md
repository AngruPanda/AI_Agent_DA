# AI Agent DA — LLM-агент для автоматизации первичного анализа данных

## О проекте
AI Agent DA — это исследовательский проект, представляющий собой AI-агента для автоматизации первичного анализа табличных данных. Агент предназначен для помощи людям, которые не сильны в программировании и аналитике, а также для тех, у кого нет времени на детальное изучение данных вручную.

Агент сочетает в себе возможности больших языковых моделей (LLM), инструментов для анализа данных на Python и RAG-системы для доступа к методологическим знаниям о работе аналитика. Проект реализован в формате Jupyter Notebook и представляет собой MVP-версию.

## Возможности
Автоматическое построение графиков — агент самостоятельно выбирает подходящий тип визуализации на основе структуры данных и вопроса пользователя.

Проверка статистических гипотез — встроенные инструменты для проведения тестирования гипотез по различным критериям.

Корреляционный анализ — выявление взаимосвязей между признаками в таблице данных.

Структурированный отчёт — формирование понятного отчёта о данных для пользователей без глубоких знаний в аналитике.

RAG-система с двухэтапным поиском — комбинация лексического поиска (BM25) и семантического векторного поиска для точного извлечения методологических знаний.

## Архитектура
Агент построен на базе LangChain и LangGraph. LangGraph используется для организации графа сценария — последовательности шагов, которые агент выполняет при анализе данных.

RAG-система реализует гибридный поиск: сначала выполняется лексический поиск BM25 по ключевым словам, затем — семантический поиск по векторной базе данных. Результаты двух этапов объединяются для повышения точности извлечения релевантной информации.

В качестве инструментов анализа используются стандартные библиотеки Python для data science: pandas, NumPy, SciPy и Plotly.

## Технологии

| Компонент | Технология |
|---|---|
| Оркестрация агента | LangChain, LangGraph |
| Работа с данными | pandas, NumPy, SciPy |

## Установка
Клонируйте репозиторий:

```bash
git clone https://github.com/AngruPanda/AI_Agent_DA.git
cd AI_Agent_DA
```

Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

Установите необходимые библиотеки:

```bash
pip install pandas numpy scipy plotly langchain langgraph langchain-community langchain-openai jupyter
```

Примечание: Для работы RAG-системы может потребоваться дополнительная настройка векторного хранилища и загрузка методологических документов.

## Использование
Запустите Jupyter Notebook:

```bash
jupyter notebook
```
Откройте файл Agent_DA.ipynb.

Поместите ваш CSV-файл с данными в корневую директорию проекта или укажите путь к нему в ноутбуке. В репозитории уже присутствует демонстрационный файл sale_data.csv — датасет с данными о продажах, содержащий информацию о заказах, суммах, категориях товаров, способах оплаты и географической привязке.

Запустите все ячейки ноутбука последовательно.

Следуйте инструкциям в ноутбуке для ввода запросов на естественном языке — агент автоматически выполнит анализ и предоставит результаты.
